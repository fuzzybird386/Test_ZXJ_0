# 实板验收记录表

以下步骤尚需连接实际 PCB 执行。不要将模拟测试结果填写为实测结果。

## 1. 上电和烧录

1. 电极暂不接溶液，检查电源极性、短路、芯片方向和焊接。
2. 确认 AVDD/VCC 满足芯片供电范围；使用示波器观察无线发送时跌落。
3. 连接 SWDIO、SWCLK、GND、VTref；首次烧录期间保持供电。
4. 使用 `ECW: Flash`，保存 J-Link 的下载/校验输出。若发现读保护，先明确是否允许擦除已有内容，再人工恢复。
5. 松开上电按钮后，确认 P0.02 为高电平且板子继续运行。

### 本次 SWD 连接失败的排查顺序

已识别 J-Link 69730362；VTref=3.282～3.293 V，但 1000 kHz 和 100 kHz 都报告 `Could not connect to the target device`。未执行下载、全片擦除或恢复。

1. 断电检查下载器 SWDIO→H1.4、SWCLK→H1.5、GND→H1.2 的通断和是否接反；不要把 H1.1（WE0）误当成调试脚。
2. VTref 要接目标 VCC，测量芯片供电脚确实有稳定电压；仅 VTref 有电不代表 MCU 已正确供电。
3. 首次下载持续按住 SW1，或按电路设计提供稳定外部供电，排除 P0.02 尚未保持导致的掉电。
4. 缩短 SWD 导线，用已确认支持 nRF54L15 的下载器交叉验证；当前下载器回报 J-Link V9.70 硬件、2022 年固件，不能仅根据安装了新版电脑软件确认其目标兼容性。
5. 检查 MCU 焊接、方向、SWD 引脚连接和芯片实际型号。只有读取到明确的保护状态后才考虑 Nordic recovery；这会擦除内容，未自动执行。

## 2. 蓝牙与 LED

|操作|预期|实测|
|---|---|---|
|开机未连接，等待超过 20 秒|绿灯持续闪烁，继续广播 ECW R1|待测|
|APP 连接|绿灯常亮，读到设备信息、电量|待测|
|启动 CV/DPV|绿灯继续常亮|待测|
|正常停止|绿灯保持常亮，电极驱动关闭|待测|
|APP 主动断开或超出范围|断连回调后红灯闪烁约 4 秒，P0.02 拉低|待测|
|重新按键开机|重新广播，绿灯闪烁|待测|

链路物理丢失到 BLE 协议栈判定断开存在 supervision timeout；4 秒从固件收到断连事件起计算，不是从手机移出射频范围瞬间计算。若按住 SW1 或调试器继续供电，固件进入 System OFF，但外部电源可能仍存在。

## 3. 已知电阻检查

将 CE 与 RE 在外部短接，10 kΩ 精密电阻接在该节点与 WE0 之间；不要接 GND。选 WE0、10 kΩ RTIA 档。先用万用表核对电阻值。

- CV：起点 0 mV，顶点1 +100 mV，顶点2 −100 mV，终点 0 mV，步进 5 mV，速率 100 mV/s，1 次循环，静置 2 秒。预期 81 个电位点；I–E 应近似直线，±100 mV 对应电流幅值约 10 µA。记录符号、斜率、零点和最大误差。
- 用差分探头/适当接地方式测 WE−RE，而非单测 RE 对地；检查 −100、0、+100 mV 与步长/周期。避免示波器地夹把电极虚地点短接到地。
- DPV：起点 −100 mV，终点 +100 mV，步进 5 mV，脉冲 50 mV，脉宽 50 ms，周期 200 ms，静置 2 秒。预期 41 点，电阻负载下 ΔI 幅值约 5 µA，且不应产生溶液特有的氧化还原峰。
- 复测反向 CV/DPV、2 次 CV 循环、非整步长终点；同时观察电位波形，确认 APP 电位点与实际输出对应。

测量误差判定须先制定标准，例如与参考仪器/负载校准比对；本项目不以“有曲线”代替精度验收。对于真实三电极体系，用已知标准溶液与商业电化学仪器对照，确认峰位、峰电流、扫描方向和重复性。

## 4. 错误与生命周期

|测试|预期|
|---|---|
|选择 WE1 或不支持的方法|返回不支持，不驱动其他 MCU 引脚|
|测量中再次 START|返回忙，不覆盖原会话|
|正常 STOP，马上再 START|旧会话 END 与新会话数据区分正确|
|测量中断开蓝牙|停止 AFE，红灯 4 秒后关机|
|断开 AD5941 或 SPI 异常|启动失败或 ERROR/END，不持续输出假电流|
|参数越界/DPV 周期≤脉宽|拒绝启动|
|长时间测量与弱信号环境|检查帧序号连续性；队列满时报错停止，不静默覆盖|
|所有 RTIA 档|逐档用合适的标准电阻验证增益，特别是高阻档和历史“200 Ω”档|

RTT 日志可用 J-Link RTT Viewer 查看；设备选择 nRF54L15_M33 / SWD，日志不占用 UART 引脚。
