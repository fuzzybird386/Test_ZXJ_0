# CV 中途停止：0x22 修订

> 本页保留 1.1.3 的历史行为和测试记录。当前 1.1.4 保留超量程修正，并统一电流符号、增加逐圈日志；最新交付见 `CV_DIRECTION_CYCLES.md`。

交付版本 `1.1.3-cv-range`，镜像 `firmware/ecw54_cqet_cv_fix.hex`。
APP 完全不修改，保留 CQET 名称和现有开机/连接/断线关机灯光。

## 根据照片和源码定位

- 设备日志的 `code=0x22` 为十进制 34，即固件 `-ERANGE` 的错误码。
- 对已成功开始并输出曲线的 CV，参数电位已被限制在 ±1000mV，DAC 编码在此范围内有效；运行中的明确触发点是 `sample_at()` 检测到 `ECW_FLAG_ADC_RAIL`，直接终止整个扫描。
- 标志来源包括原始 ADC 逼近上下限，以及 LPTIA 差分输出绝对值超过 0.85V。后者用于防止把可能非线性的电流读数当成有效测量。
- 照片最后有效电流约 -201.33µA。若当时使用 4kΩ RTIA，其保护阈值约为 0.85V/4kΩ=212.5µA，与临近停止的曲线相符。照片未显示档位和全部参数，不能据此认定实际 RTIA 或排除硬件接线/供电/输出限幅问题。
- `code=0x10` 为十进制 16，即 `-EBUSY`：上一个测量任务尚未结束时又收到启动请求。新版明确提示先停止并等待；不会通过强行覆盖正在运行的任务处理忙状态。

## 本次修改

CV/CA 某个采样点饱和时，保持该点电位，按现有八档 RTIA 向较低阻值换挡，等待 2ms 后重新采样；最多七次降档，最低 200Ω。换挡仅改 LPTIACON0 的 TIAGAIN 位，保持 DAC、PA、电极开关、RLOAD 等配置。
每次以实际使用的 RTIA 换算 nA，APP 仍接收原有电流单位与帧结构。饱和样本不上传；不能恢复则仍返回超量程错误。

APP 选定档位作为每次 START 的初始灵敏度，运行中只在检测到超量程后降低增益，不自动升回。重新 START 时恢复 APP 本次请求档位。较低 RTIA 能容纳较大电流，但小电流分辨率可能降低；原 RTIA 标称值/比例校正方式保留，没有新增实板自动校准。

成功换挡会产生 WARN 日志 `Current range widened; saturated sample remeasured`，code=0x100；警告不会点亮红色错误灯。CV 按实际采样结束时间继续后续步进，避免因换挡延迟而连续追赶或误报超时。因此换挡点可能额外停留，局部扫描时序并非严格等间隔。

DPV 为避免改变双阶段脉冲采样时序，不启用本次自动换挡；OCP 无电流 RTIA 换挡。EIS 保留其独立复数测量与保护。CA 保留实际时间戳及采样期限检查；若换挡代价跨越后续采样期限，仍可能报告采样超时。

通用失败日志改为区分超量程、采样期限超出、AFE 采集超时及其他故障，不再仅显示笼统的 “check range, timing and AFE”。

## 实测复验

用户随后确认原参数：WE0、225µA 档（APP gear=2，固件 RTIA=4kΩ）、起始/第二顶点/终止均 -600mV、第一顶点 +1000mV、100mV/s、5mV、四圈、静置 5s。已将这组原始 START 字节加入真实协议解码与测量代码回归测试：在首次 +280mV 注入饱和事件，确认先重采样再继续，最终四次到达 +1000mV 并返回 -600mV，完成 2561 个采样点。理想时序包括静置约 133.05s，实际换挡延时及硬件采样可能延长。测量流程测试由 82 增至 93 条断言并通过。

225µA 为 APP 标称范围，而旧固件 0.85V 保护阈值对应 212.5µA，两者不一致，能解释在标称量程前触发保护。+280mV 的饱和由测试模型注入，测试不代表复现了真实电极电流，也不能证明实际饱和电位固定为该值。本次仅补充测试和说明，交付 HEX 及 1.1.3 版本不变，无需再换一份镜像。

烧录本页镜像，断电重启，在原 APP 设备信息确认 `1.1.3-cv-range`。用原 CV 参数和同一已知负载重测，确认完成正反向扫描，查看是否出现换挡警告。
若仍出现超量程，提供当时的量程档位、CV 参数和新版日志。可先用较低 RTIA 档测试；较低电阻对应更大的电流范围。
本次自动换挡只解决采样增益饱和后的中止策略，不能增加板子的恒电位输出电流或补偿电极接线、短路、共模和供电异常。不要把饱和/削顶曲线解释为真实电化学峰。
