## 结论及改动

1. **扫描没有按电位排序，也没有把四圈写成四个单程。** `run_cv()` 每次循环执行两段：当前电位→第一顶点，再第一顶点→第二顶点。对用户参数就是四次 -600→+1000→-600mV。每个采样点共享同一 session，序号连续，最后才发送一个 END。
2. **原电流换算的负号与 APP 阳极为正的约定相反。** LPTIA0_P 为输出、LPTIA0_N 为负输入/求和节点。按氧化电流（常规电流从 WE 流向电解液）为正的约定，反馈输出供应流出 WE 的电流，因此 `I=(Vout−V_WE)/RTIA`。原代码的 `-Vtia/RTIA` 报告的是相反方向。现在 CV/CA/DPV 的电流统一为 `+Vtia/RTIA`，电位方向和 EIS 的独立复数公式没有翻转。DPV 两次原始电流随之改变符号，APP 仍按原方式求差。
3. **APP 将一次完整测量硬编码为 CV Scan 1。** `BleBackedMeasurementRepository.kt` 的 CV 结果构造固定 `index=1`、`cycles=listOf(cycle)`，接收的全部点按到达顺序放在该对象内。`CVScreen.kt` 按对象数生成选择按钮和记录行。固件不能改变这个列表长度。逐圈发送 END 会让 APP 第一圈就结束接收，因此没有采用这种做法。
4. APP 的 Ipa/Epa 只是全部点中的最大电流及其电位，Ipc/Epc 为全部点中的最小值。没有先拆分正反向，也没有按每圈做电化学峰识别。因此这些标记的位置和画面出现顺序不能直接当作采集时间顺序，更不能单独证明扫描电位反向。

电流符号修正以电路节点及常规电流定义为依据，截图的正负峰位置也与原符号相反的表现相符。真实电位输出、接线极性、化学反应及峰位仍需实板验证，不能用改变电流符号保证任何溶液都先出现某个峰。

## 在不改 APP 的前提下确认四圈

新版通过原 APP AABE 设备日志报告每一圈的两段起止电位、后续数据序号及完成后的总点数。完整成功运行可看到：

| 日志 | 累计采样点数 | 最后采样序号（0 起算） |
|---|---:|---:|
| CV 1/4 done | 641 | 640 |
| CV 2/4 done | 1281 | 1280 |
| CV 3/4 done | 1921 | 1920 |
| CV 4/4 done | 2561 | 2560 |

每单程 320 次步进。相邻圈共用真实的 -600mV 边界点，不重复采样来凑数量。静置 5s 后扫描约 128.05s，总计约 133.05s，换挡/调度可能增加时间。
逐圈完成日志表示采样点已经进入固件发送队列，不能单独证明手机收齐了每一条通知。后续无线发送故障仍会报告错误。

原 APP 的一条蓝色曲线包含四圈时间顺序数据，形状相近时会重叠；在 APP 不改的约束下，不能生成四条可分别勾选的记录。用户可用原 APP 保存/导出 CSV，核对 **2561 个数据行**和下面的电位序列：

`-600 → +1000 → -600 → +1000 → -600 → +1000 → -600 → +1000 → -600 mV`

CSV 的 `cycle` 列仍会全部为 1，这是 APP 的记录编号，不是物理圈计数。项目附带 `tools/check_cv_csv.py`，按原始点顺序核对完整步进及四次往返，并拆出四个 CSV，不排序、不补点、不翻转电流。原 APP 元数据缺失时使用本次参数作为默认值。

```powershell
python tools/check_cv_csv.py "手机导出的CV.csv" --out "cv_check_result"
```

输出目录必须尚不存在。成功时有 `report.json`、`cycle_1.csv` 至 `cycle_4.csv`，每圈包含实际共享边界的 641 个点；缺点或错序时返回 FAIL，不把不完整结果伪装成完整四圈。若原 APP 当前入口仅保存而不能分享 CSV，请提供实际保存文件；此工具不要求修改 APP。

CSV 没有原始 BLE 序号或时间戳，因此这项检查只证明点数与电位模式一致：完全相同的圈互换、或对称三角扫描整条倒序后电位模式不变时，不能靠 CSV 识别。固件逐帧序号测试和运行日志是额外证据，也不能代替真实无线抓包与电极电位实测。

## 建议实板核对

先用独立的已知 10kΩ 电阻替代电化学池：电阻一端接 WE0，另一端接并在一起的 RE/CE。先使用 -100→+100→-100mV 的小范围扫描，以万用表/示波器实测 WE−RE：正向时应增加，反向时应减小；+100mV 对应约 +10µA，-100mV 对应约 -10µA（考虑实装阻值和板内阻）。再恢复真实电极，使用用户原参数验证峰与四圈数据。不要在没有实测证据时反接电极或反转输出电位。
